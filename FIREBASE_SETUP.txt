PURIXA CRM v20.1 - FIREBASE SETUP

1. Firebase Console -> create/open a project.
2. Project settings -> Your apps -> Web app -> register/add app.
3. Copy the firebaseConfig object.
4. Authentication -> Sign-in method -> enable Email/Password.
5. Firestore Database -> Create database.
6. Open the CRM and Settings -> Configure Cloud.
7. Paste the firebaseConfig JSON and Save & Connect.
8. On the login screen enter admin email/password and choose Create Admin Account (or Login if already created).

Recommended Firestore rules for this CRM:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

The web Firebase config is not a password. Security comes from Authentication and Firestore rules.
